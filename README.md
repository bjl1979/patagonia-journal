# Field Journal

An offline travel and wildlife diary. Voice notes, typed notes and photos, each stamped with the time and GPS position, grouped into trip days, with a running species list.

## Install on your phone
- **iPhone:** open the link in Safari → Share → **Add to Home Screen**.
- **Android:** open the link in Chrome → menu → **Install app** (or Add to Home screen).

Open it once with internet so it saves itself for offline use. After that it works with no signal.

## Before you travel
- Allow **Location** and **Microphone** when the app asks.
- Do a test entry of each type and a test backup.

## Backups
Everything is stored only on the phone. Use **Backup → Save backup** whenever you have Wi‑Fi and send the file to OneDrive, Drive or email. To combine two phones, open one phone's backup on the other with **Open a backup / merge another phone**.
